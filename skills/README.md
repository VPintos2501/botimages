# ✨ Iconos de Habilidades Pasivas

Formato recomendado: **128x128 px**, formato **PNG transparente**.

Tipos de habilidades principales:
- `cooldown.png` → Habilidades de reducción de tiempo de espera.
- `coins.png` → Habilidades de bonus de monedas.
- `xp.png` → Habilidades de bonus de experiencia.
- `extra_item.png` → Habilidades de probabilidad de ítem extra.
- `double_drop.png` → Habilidades de probabilidad de doble botín.
