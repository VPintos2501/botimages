# 🎨 Repositorio de Imágenes del Bot RPG

Este repositorio contiene las imágenes y assets gráficos utilizados en el Bot de Economía RPG Medieval de Fantasía.

---

## 📁 Estructura de Carpetas

- **[`items/tools/mining/`](./items/tools/mining/)** → Imágenes de Picos de Minería (Tier F a EX).
- **[`items/tools/fishing/`](./items/tools/fishing/)** → Imágenes de Cañas de Pescar (Tier F a EX).
- **[`items/materials/mining/`](./items/materials/mining/)** → Minerales y piedras extraídas (Tier F a EX).
- **[`items/materials/fishing/`](./items/materials/fishing/)** → Peces, corales y criaturas acuáticas (Tier F a EX).
- **[`zones/mining/`](./zones/mining/)** → Ilustraciones o banners de las 13 Minas.
- **[`zones/fishing/`](./zones/fishing/)** → Ilustraciones o banners de las 13 Zonas de Pesca.
- **[`ranks/`](./ranks/)** → Emblemas de los 13 Rangos (EX a F).
- **[`skills/`](./skills/)** → Iconos de Habilidades Pasivas.

---

## 📐 Especificaciones de Imágenes

- **Ítems / Materiales / Herramientas:**
  - Tamaño recomendado: **128x128 px** o **256x256 px**.
  - Formato: **`.png` con fondo transparente**.
  - Relación de aspecto: **1:1 (cuadrada)**.

- **Banners de Zonas:**
  - Tamaño recomendado: **1024x512 px** o **1280x720 px**.
  - Formato: **`.png` o `.jpg`**.
  - Relación de aspecto: **16:9 o 2:1**.

---

## 🔗 Formato de Enlace Directo (Raw URL)

Una vez subida una imagen a este repositorio (rama `main`), su enlace directo para la base de datos es:

```
https://raw.githubusercontent.com/VPintos2501/botimages/main/<ruta_del_archivo>
```

*Ejemplo:*
`https://raw.githubusercontent.com/VPintos2501/botimages/main/items/tools/mining/pico_madera.png`
